# AfterLife OTA repo
In order for a device to be officially supported by Afterlife, OTA information needs to be added.

## How to fill
How to fill your updates data and changelogs:
Make sure you should create a new folder for your device codename, then follow this templates:
- [Updates](https://github.com/AfterlifeOS/device_afterlife_ota/blob/16/templates/updates.json)
- [Changelogs](https://github.com/AfterlifeOS/device_afterlife_ota/blob/16/templates/changelog.md?plain=1)
